# Tapeout API Market（TAM）

**去中心化 AI API 市场。**

## 为什么需要 TAM？

比如，你做了一个每天帮你整理资料的 Agent。它需要反复调用模型，你希望找到可用的接口、比较报价，还得控制一天花多少钱。换一家提供者，又可能要改配置、重新接接口。另一边，有人运行着模型节点，想把空闲容量挂出来卖，忙起来又需要减少接单。

在 TAM，卖家发布模型和价格，买方网关从同模型、同结算币的卖家里选择。用多少付多少，完整收到回答后才签付款账单。你的 AI 也可以在你设定的额度内操作。

还有一个实际问题：回答传到一半断了，这钱付不付？TAM 会检查完整响应，检查失败就不签最终付款账单。卖家收到的多张账单可以合并收款，分摊小额调用的链上手续费。

## 怎么用？

1. **卖家发布服务。** 告诉网络能提供什么模型、价格是多少；可以固定价，也可以让 AIMM 自动调价。
2. **买家准备预算。** 把结算币存进链上托管合约，设置单次和每日额度。没用完的预算可以申请退回。
3. **网关比价下单。** 买方网关比较同币种、同结算池的服务，选择可用卖家，先锁定价格与最高费用，再发送问题。
4. **收到完整回答。** 内容逐段显示。买方检查回答完整、非空，报告用量没有超预算；断流或检查失败，不签最终付款账单。
5. **链下签收账单。** 买方按锁定价格和报告用量计算费用，在你授权的规则内签名，无需每次手动点，也无需每次调用都发起链上交易。
6. **卖家批量收款。** 卖家保存多张签名账单，一起提交合约。合约核验后付款，并防止重复收款。

充值预算需要上链；每次调用的预算意向和最终账单在链下签署，不会每次都向合约发送交易来锁钱。最初的预算意向不能直接收款，卖家需要完整交付后的最终签名。

## 五个技术特点

### 1. AIMM 动态定价：价格跟着忙闲走

卖家设底价和调价规则，程序根据负载自动报价：空闲时回到底价，忙碌时上调，减少手动改价。卖家也可以选择固定价。报价带签名和有效期，每次调用先锁价，中途不会跟着涨价。

### 2. 链下签名 + 链上托管 + 批量结算：让小额调用更划算

预算由链上合约托管，每次完整调用后在链下签一张付款账单。卖家把多笔账单合并到少量链上交易，分摊手续费，避免一次调用对应一笔交易。

充值、批量收款和退回预算仍需 Gas；节省多少取决于批次大小和网络费用。每笔账单仍独立核验，不能重复收款。

### 3. 去中心化节点：买方网关自己比价、选卖家

卖家向 P2P 节点网络发布服务，买方网关比较报价和可用状态，自主选择卖家。**没有中心调度服务器统一分派订单**；报价可比较，选择权在买家，减少平台分派对交易的影响。

引导与中继节点帮助建立连接，不替买家选卖家，也不代签付款。网站、连接节点和上游模型仍有服务器组件；这里的去中心化指发现、选路和授权机制。

### 4. AI 原生：AI 负责操作，你掌握额度与权限

你的 AI 可以自己调用服务、补充预算、收款、提议改价，不用你每次手动点。你设单次与每日预算、可用模型、充值额度、调价范围和操作权限；程序按规则执行，记录结果，并支持暂停后续自动操作。

TAM 提供兼容 API、SDK 和本地管理工具，接入你自己的 AI 即可。详见 [AI 操作说明](agent-first-operations.md)。

### 5. 预留 ZK 接口：为减少模型冒充与“注水”做准备

卖家说提供官方模型，买家怎么验证？项目已预留证明生成和买方验证接口，未来可接入 **zkTLS**，核验回答是否来自指定官方服务、是否对应本次请求，并将验证结果接到付款确认之前。

**接口已预留，真实 zkTLS 验证尚未接入。** 当前模型来源和用量仍由卖家声明。未来证明的目标是验证请求与官方服务响应的关联；它不直接证明内部模型权重，也不保证答案正确。详见 [zkTLS 接口说明](model-provenance-zktls.md)。

## 当前进展

项目处于 **BSC 测试网（Chain 97）内测**，支持 tUSDC / tBEM 分别报价和结算，不自动换币。买卖网关、P2P 发现、AIMM、流式调用、交付后签名、批量收款和 AI 管理接口已实现；网站与命令行客户端支持中英文。

内测采用卖家审核买家的方式，主网尚未启用。独立安全审查、公开交易争议处理与真实 zkTLS 验证仍待完善。

## 协议如何收费？

当前测试配置收取已结算服务费的 1%。例如 100 结算币的服务费，卖家收到 99，协议收到 1；Gas 另计，费率可由合约管理员调整。测试币结算不计为商业营收。

先从开发者和 Agent 用户开始，增加独立卖家，观察完成调用量、成功率、重复使用和结算成本。目前没有可公开的团队、融资目标或商业用户数据。官网展示的卖家、模型和入口节点数只是当前网络观察结果。
