# TAM 本机客户端入口

命令行里的买家／卖家菜单运行 `corepack pnpm tam console`。此台开发电脑桌面的 `TAM客户端.cmd` 使用这个入口。菜单、顶部状态和底栏固定在终端窗口内；长内容用 PgUp / PgDn 在右侧翻页，选中的操作和输入框会自动保持可见。建议窗口至少 80 列、24 行；缩小后显示单行菜单导航，Tab 仍可切换视图。

网页操作界面运行 `corepack pnpm tam ui`，使用方式如下。

日常聊天和查看余额可以使用浏览器界面，后台仍然是现有的本机买家节点。界面服务只监听 `127.0.0.1`，不会部署到公网市场网站。

在仓库根目录构建并启动：

```powershell
corepack pnpm cli:build
corepack pnpm tam ui
```

默认自动打开浏览器。USDC 配置使用 `http://127.0.0.1:18500`，BEM 配置使用 `http://127.0.0.1:18501`。使用 `--no-open` 只启动后台，`--port` 可以调整界面端口。同一付款配置只允许一个界面后台；重复启动默认入口会打开已有实例。付款配置切换仍使用 `tam payment use USDC` / `BEM`，在下次启动生效。

浏览器页面可以关闭；网页界面的后台进程需要保留。买家已经运行时直接连接原买家；尚未运行时，在「设置与接入」点击「启动本机买家」。命令行控制台退出时会清理该次控制台启动的买家／卖家进程。

## 界面怎么用

- **智能问答**：常驻输入框；Enter 发送、Shift + Enter 换行；中文输入法的确认键不会发送消息。回答流式显示，代码可复制。阅读前文时不会被新内容拉到底部；「回到最新回复」可回到末尾。
- **服务市场**：显示买家实际发现的模型、卖家和输入/输出报价，点击即可选择模型。
- **钱包与充值**：分别显示调用额度、钱包测试币、测试 BNB 手续费。充值和提现先展示确认信息，再执行原钱包接口。提现解锁时间由买家返回，尚未解锁时不能完成提现。提供公网测试币和 Gas 指引入口。
- **AI 管理**：查看自动操作预算、活动和主人规则，支持修改已有权限与额度、暂停/恢复原授权。未保存的表单不会被状态刷新覆盖。卖家最低价/最高价等详细规则仍通过原控制台或 `tam agent policy` 配置。
- **设置与接入**：查看本机连接和 AI 接入地址，启动买家。界面展示 API 令牌占位符，实际令牌继续保存在原私有文件中。

菜单切换不重建聊天内容或输入框。状态刷新只更新对应数据。聊天草稿和阅读位置在菜单切换、浏览器刷新后保留。

## 连续对话与操作恢复

每个对话发送当前问题和最近最多 19 轮完整问答，累计最多 64,000 个字符；过长时按完整轮次移除最早前文。一条消息最多 16,000 个字符，单次回答上限 4,096 Token。不完整回答不会自动作为下一轮前文。对话没有无限记忆。

浏览器最多保存 20 个对话，每个最多保留最近 100 条消息，按付款配置和钱包区分。这些记录保存在当前浏览器的 localStorage；清理浏览器数据或更换浏览器会丢失。对话中的用户消息会在调用时发送给选中的模型服务。

后台为每次聊天和钱包操作保存固定编号。在保留的操作记录范围内，同一编号和参数只执行一次；刷新或连接断开后查询原编号，不重新调用。关闭浏览器不会取消已经提交的请求，原请求仍可能完成和结算。同一界面后台一次只接受一个聊天或钱包操作。

后台重启前仍在运行的操作会标记为「待核对」，保留部分回答并停止自动重发。请查看余额、原请求和交易记录；不要通过换编号立即重试付款。后台保存最近最多 200 项操作，完整历史不是永久账本。

## 本机访问与数据

后台用本机 HttpOnly 会话 Cookie 保护接口，校验 Host、Origin 和跨站请求。钱包私钥及买家/AI 接入令牌由原后台使用，不返回网页。操作记录存放在付款配置数据目录的 `client-ui/operations.json`，包含回答、用量和结果，属于本机私有数据，不提交到仓库。同一目录受内核监听锁保护，避免不同 UI 端口同时写入。

当前仍是 **BSC 测试网 Chain 97 内测**。界面不改变原网关的付款限额、许可买家规则、模型来源与交付确认边界；公网市场网站负责展示和测试币领取，本机界面负责使用自己的买家和钱包。
