# GPT-6 Luna 公网卖家初始报价

2026-10-07 核对的 [OpenAI 官方 GPT-6 Luna 页面](https://developers.openai.com/api/docs/models/gpt-6-luna)与 [官方定价页](https://developers.openai.com/api/docs/pricing)说明，Standard、短上下文、非缓存文本输入的 API 价格为：

| 每百万 Token | 官方 API（美元） | TAM 初始价（tUSDC） |
| --- | --- | --- |
| 输入 | 0.10 | 0.02 |
| 输出 | 0.50 | 0.10 |

卖家初始价格按官方标准价格的 **20%（二折）** 设置，分别保留输入和输出费率。当前只在 BSC 测试网使用项目测试 tUSDC；这不是主网美元付款，也不能把 tUSDC 视为有美元价值的资产。

公开配置见 [gpt-6-luna-bsc-testnet.json](../deploy/pricing/gpt-6-luna-bsc-testnet.json)。初始动态参数为 `p0=0.06`、`alpha=0`、`quotePriceCeiling=0.06`，以固定费率开始。动态 scalar 引用两种费率的基准，买卖双方锁定输入/输出价格时按同一比例调整，不再把两者改成同一个价格。主人后续仍可以选择调价。

公网配置和真实微量付款已验证，见 部署与调用证据（运行记录仅保存在本地）。

BSC tUSDC 的最低单次金额为一个最小单位，即 **0.000001 tUSDC**。实际金额根据已交付用量计算并向上取整到六位小数，避免旧的 0.01 最低费用把短请求价格抬高。例如输入 315、输出 13 个 Token，二折价的数学费用为 0.0000076，链上金额为 0.000008 tUSDC。极小请求因精度取整，实际比例可能略高于 20%。手续费从卖家收入中按合约计算，不额外加在买家价格上；小金额的手续费会受六位精度限制。

此最低费用是应用协议规则，已有链上池接受最小单位金额，因此没有重新部署代币或结算池。旧的主网 BEM、测试 BEM和旧 USDC 网络配置保持原最低金额。BSC USDC 买家、卖家、Hosted Gateway 与 SDK 需一起更新；新的发现检查和 SDK 会拒绝不一致的最低费用元数据。既有余额、签名域、nonce 和已收款记录保持。

当前没有分别计价缓存输入、缓存写入、长上下文档位或外部工具调用。对比基准明确为 Standard 短上下文非缓存 API 价；会员账户额度不是 API Token 采购成本。当前阶段验证的是测试网报价和付款逻辑，没有承诺主网经营收益。
