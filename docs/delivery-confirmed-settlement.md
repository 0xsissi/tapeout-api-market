# 本次修复与内测使用说明

这次修复保留 Tapeout API Market (TAM) 项目名称，将 P2P 通信协议升级为 **3.0.0**。买方网关、卖方网关和 SDK 必须一起更新。旧客户端不能直接接入新的付费流程。

## 付款现在怎样发生

1. 买家先签 `ClawInferenceIntent`：限定卖家、请求编号、加密请求摘要、固定价格、输入和输出预算、最高金额、授权编号及有效期。
2. 该签名使用单独的 EIP-712 域和类型，不能当作 `ClawEscrowPool` 收款授权使用。卖家先验证并持久化占用这份预算，防止并发复用。
3. 卖家交付完整响应和用量。上游断流、缺少结束标记、缺少用量或用量超预算时，流程失败，不签最终付款。
4. 买方网关或 SDK 收到完整、非空的结果后，按本次锁定价格与报告用量计算金额，再签合约可收取的最终授权。保留原有每请求 **0.01 USDC 最低收费**。
5. 卖家先持久化最终授权，再回传确认。确认丢失时，本地买方返回 `settlement_uncertain`，不会自动换卖家再付一次。此状态需要核对收款记录或链上交易，不能当作肯定没有付款。

已有 EscrowPool 可以验证最后的付款签名，本次没有修改、重新部署或升级链上合约。新预算签名不能被现有合约兑现；历史版本已经签发的付款授权仍遵循原有合约规则。

## 当前的信任边界

收到结果再签付款能保护买家，但买家仍可能拿到结果后拒绝确认。程序没有实现链上服务争议裁决或模型真实性证明，因此默认只服务人工核验的买家。卖家需配置 `trustedBuyerAddresses`，或使用环境变量：

```powershell
$env:CLAWMARKET_TRUSTED_BUYERS = '0x实际买家钱包地址,0x另一个已核验买家地址'
```

未配置名单时拒绝付费推理请求。默认单次最高预算为 **0.10 USDC**；每个买家累计尚未确认的预算最多 **0.10 USDC**，通过 `ProviderConfig.maxRequestCostUsd`、`maxUnconfirmedCreditUsd` 调整。失败或拒绝确认的请求会保留占用直到意图过期，避免免费反复执行。意图有效期最长 15 分钟。

上游成本的每日限额在请求执行期间预留，拒绝确认也会计入成本；中途失败且实际用量未知时按最高预算保守计算。这不是精确的上游账单对账。

报告用量来自卖家上游，校验范围是格式、固定价格和预算，不能证明模型供应商或 token 数量真实。跨卖家的余额竞争也没有链上统一预留机制。公开接收陌生买家、模型身份验证和争议仲裁仍需进一步设计及独立审查。

## 本地访问令牌

买方 HTTP 网关继续绑定 `127.0.0.1`。除 `/health` 外的接口需要 `Authorization: Bearer <令牌>`。令牌首次启动自动保存到 `~/.clawmarket/api-token`；CLI 会读取该文件。其他 OpenAI 兼容客户端应把令牌作为 `api_key` 使用，而不是填钱包私钥。

也可通过 `ConsumerConfig.apiToken` 或 `CLAWMARKET_API_TOKEN` 配置至少 32 字符的令牌。买方网关和 TypeScript Agent SDK 默认限制单次预算 0.10 USDC；较大请求需要显式设置 `maxRequestCostUsd`，并同步卖方限制。Python 对应 `max_request_cost_usd`。

托管网关默认绑定本地地址。公开部署需配置 HTTPS 反向代理；程序增加了请求体上限、连接上限、每 IP 请求限制、准备请求数量和内存限制。只有更新后的 SDK 完成 `/v1/claw/settle` 最终付款确认，标准 OpenAI 客户端应接本地买方网关。

代付 gas 接口额外需要 `CLAWMARKET_HOSTED_API_TOKEN`，至少 32 字符；TypeScript SDK 配置 `gatewayToken`，Python 配置 `gateway_token`。未配置访问令牌时不开放代付接口。

## 收款记录与崩溃恢复

记录按链、资金池和卖家地址分别保存到 `~/.clawmarket-provider/<chainId>/<pool>/<seller>/`。匹配卖家和资金池的旧版待收款记录会复制到对应目录，原文件保留。复制不证明旧记录对应的服务已经交付，也不能跨链验证旧授权。

写入使用临时文件、刷盘和原子重命名。损坏的收款记录会阻止启动并保留原文件，不再清空队列。最终收款授权先保存，预算占用后释放；重启仍拒绝重复使用尚未完成的授权。

每个卖家目录有 `ledger.lock`，防止两个进程同时写同一账本。正常停止会释放锁。若进程崩溃留下锁，先核对锁文件中的 PID，确认旧进程已停止，再移除该锁文件；不要删除收款 JSON 文件。自动删除未知锁可能使两个进程并发写账本，因此当前采用人工确认恢复。

## 验证方法

```powershell
corepack pnpm install --frozen-lockfile --ignore-scripts
corepack pnpm -r build
corepack pnpm test
```

Python SDK 单独安装测试依赖并运行：

```powershell
cd packages/agent-sdk/python
python -m pip install -e '.[test]'
python -m pytest tests -q
```

新增测试使用随机或固定测试密钥、模拟链上状态以及本地 HTTP 上游，覆盖真实 EIP-712 签名、实际费用结算、并发占用、重启恢复、损坏账本、断流、未确认交付、钱包鉴权、付款确认丢失，以及托管 SDK 的普通和流式交付。它们没有花费真实资金或调用付费上游。

代码修复和本地测试不等于已完成生产验证。主网合约、真实供应商、独立引导节点、真实网络持续运行和独立安全审查仍需在部署阶段完成；本次仍使用原有测试网默认配置，也没有改为 BEM。
