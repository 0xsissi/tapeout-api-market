# Tapeout API Market Pitch Deck v1
## 给投资人的路演 PPT — 逐页设计稿

> **用途**：种子 / Pre-A 轮路演
> **时长**：12-15 分钟正式讲 + 问答
> **风格**：简洁、数据密度高、少字多图
> **核心情绪**：不是"一个有意思的 idea"，而是"一个必然会发生的未来，我们在正确的时间做正确的事"

---

## 设计总原则

- **每页只一个 key message**，能一句话说完
- 字数严格控制：标题 ≤ 12 字，正文 ≤ 40 字，页面总字数 ≤ 80 字
- **数据用大字号**，文字用小字号。投资人要的是信号，不是段落
- **不用 emoji**（太轻）、**不用 Web3 行话**（AMM/DeFi/zk 这些投资人如果是传统 VC 会劝退）
- 页脚统一：`TAM · Confidential · 2026`
- 色调建议：黑底 + 白字 + 橙红点缀（类比 Stripe / Linear / Vercel 的现代科技感，避免 Web3 常见的霓虹蓝紫）

# 第 9 页：护城河（Moat）

**标题**：为什么这不是"另一个 OpenRouter 的 fork"

**四象限**：

**① 双边网络效应**
- Provider 越多 → 价格越有竞争力、可用性越高
- Buyer 越多 → Provider 越愿意加入
- **先达到最小可行规模的协议赢者通吃**

**② 信誉数据不可 fork**
- 两年累积上亿条 (request, provider, quality) 数据
- Fork 代码容易，fork 不走"谁在哪些场景下表现最好"的实战数据
- **类比**：Uniswap 之后 SushiSwap 吸血鬼攻击失败，因为 TVL 和集成关系 fork 不走

**③ Agent 生态锁定**
- 一旦主流 agent 框架（LangChain、Vercel AI SDK、Anthropic MCP）把 Tapeout API Market 作为默认 backend
- 迁移意味着整个 agent 生态要同步改
- **类比**：Stripe 早期锁定 Shopify / Squarespace 后再也没被撼动

**④ 合规套利的时间窗口持续扩大**
- 中心化玩家越成熟，合规负担越重
- 去中心化协议在这个维度上的优势**随时间线性增长**，不是阶段性优势
- 这**不是**"我们可选择去中心化"，这是**"只有去中心化架构能承接这部分需求"**

**演讲要点（90 秒）**：
- 经验丰富的投资人都会问 "为什么别人不能 fork 你"
- 前两条是 Web3 项目的标配答案（网络效应 + 数据资产）
- 后两条是 Tapeout API Market 独特的：agent 生态锁定 + 合规套利窗口扩大
- 特别强调第 4 条：**这不是一般的护城河，这是只有我们这类架构才能吃到的结构性红利**

# 第 10 页：商业模式与代币经济

**标题**：协议收入 = 代币价值

**左侧：现金流路径**

```
  Buyer 付款                 1 USDC
         ↓
   EscrowPool 合约
         ↓
  ├─→ 99% 给 Provider
  └─→ 1% 协议费
         ↓
  ├─→ 70% 给 CLAW staker
  ├─→ 20% 进入 Treasury (DAO)
  └─→ 10% 回购销毁 CLAW
```

**右侧：CLAW 代币三功能**

1. **Provider 质押担保**：最低 100 USDC 等值的 CLAW 才能挂单，作恶 slash
2. **挖矿激励**：结算 1 USDC → mint X 个 CLAW 给 provider（X 随阶段递减：100→50→25→10）
3. **治理**：费率、参数、仲裁规则由 CLAW 持有者投票

**底部：经济模型的三个关键设计**

- ✅ **代币发行与真实经济绑定**：不是 pre-sale 凭空稀释，每一个 CLAW 都对应已发生的交易
- ✅ **递减发行 → 自然过渡**：早期高补贴解决冷启动，后期切换到手续费驱动
- ✅ **回购销毁 + Staking 分红 → 双重价值捕获**：持有 CLAW 的人直接是协议经济的受益人

**示例单位经济学**：
- 月结算 $500 万 → 月协议费 $5 万 → 年化 $60 万 → 回购 $6 万 / 年

**演讲要点（60 秒）**：
- 投资人看 Web3 项目最怕"叙事很大但拿不到钱"
- 我们直接告诉他：协议费 1%、70/20/10 分配、回购销毁机制已经写进合约
- 月结算额 = 协议收入 = 代币价值——**数学关系清晰**

# Q&A 预备题（必练）

投资人最常问的 10 个问题，你必须背熟答案：

1. **为什么是现在？为什么不是 2 年前 / 2 年后？**（见第 6 页）
2. **为什么别人不能 fork 你？**（见第 9 页护城河）
3. **Agent 经济真的会在 3 年内爆发吗？如果没呢？**
   - 答：即使 agent 慢 2 年，我们的第一波目标（长尾供给 + 受限地区）已经足够支撑 $1M/月结算
4. **监管风险？**
   - 答：协议本身无运营实体；基金会在新加坡/开曼；法律意见已准备
5. **上游 API 账号封禁风险？**
   - 答：协议不关心供给来源，风险由 provider 承担，slashing 机制约束
6. **冷启动谁先来？**
   - 答：CLAW 挖矿高发行率解决 provider 侧、Hosted Gateway + SDK 解决 buyer 摩擦
7. **和 OpenRouter 直接竞争会怎样？**
   - 答：不直接竞争，服务不同用户群。OpenRouter 也可以成为 Tapeout API Market 上的一个 provider
8. **代币会不会被认定为证券？**
   - 答：CLAW 有清晰的 utility（质押 + 治理 + 挖矿奖励），发行与真实经济绑定，非 pre-sale
9. **退出路径？**
   - 答：(a) Token 流动性本身即可退出 (b) 协议层基础设施被大型交易所 / 钱包收购先例多（参考 1inch、CoinGecko）(c) 长期持有分享协议收入
10. **你们团队能做出来吗？**
    - 答：放事实——已经做到了哪些（Base Sepolia 部署、40 项单测、Claim Batching）+ 团队核心背景（填你们的）
