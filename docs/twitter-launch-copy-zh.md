## 线程版

### 1/7 · 痛点

买家想用 AI，却要一家家找模型、比价、接接口。

卖家有容量，却难找到订单，忙闲变化还要手动改价。

每次小额调用都上链？手续费可能比调用费还高。

Tapeout API Market（TAM）把这些事连成一套流程。

### 2/7 · 怎么用

卖家发布模型与价格，买家把预算存进托管合约。

买方网关自己比价选卖家，锁价后调用。收到完整回答、通过用量检查，再在链下签一张电子账单。

卖家保存账单，攒多笔后一起上链收款。你也可以授权自己的 AI 来操作。

### 3/7 · AIMM 动态定价

API 价格跟着忙闲走。

卖家设底价和调价规则，AIMM 根据负载自动报价：闲时回到底价，忙时上调，也支持固定价。

每次调用先锁定价格，中途不会跟着涨价。

### 4/7 · 小额调用，批量结算

链下签名 + 链上托管 + 批量结算。

预算在合约里，每次完整调用后在链下签账单。多张账单合并到少量交易，分摊 Gas；合约独立核验每笔授权，防止重复收款。

充值、批量收款和退回预算仍需手续费。

### 5/7 · 去中心化节点

卖家向节点网络发布服务，买方网关自己比价、选卖家，没有中心调度服务器统一分派订单。

报价可比较，选择权在买家。

引导和中继帮助连接；网站、节点与上游模型仍有服务器组件。

### 6/7 · AI 原生

你的 AI 可以调用服务、补充预算、收款、提议改价，不用每次手动点。

额度和权限由你设定。程序拦截超限操作、记录结果，你可以暂停后续自动操作。

TAM 提供接口与工具，接入你自己的 AI 即可。

### 7/7 · 为模型来源验证留好接口

卖家说是官方模型，怎么减少冒充与“注水”？

我们预留了 zkTLS 证明生成与验证接口，未来核验回答是否来自指定官方服务、是否对应本次请求，再决定签不签付款账单。
